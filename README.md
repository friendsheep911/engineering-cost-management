# 青海信息价查询系统 —— 方案说明

> 结论先行：**能做，而且已经做好了。** 本目录就是一个可直接双击打开、可长期持续更新的
> 信息价查询系统，已用《青海工程造价管理信息》2026年7-8月（总第171期，191页）完成实测。

---

## 一、为什么"能做"——技术方案对比

| 路线 | 做法 | 优点 | 缺点 | 评价 |
|---|---|---|---|---|
| **A. 纯前端 + 数据文件（本方案）** | PDF → Python 抽取 → `data/<期号>.js`，HTML 直接读 | 双击即用、零部署、可拷贝、离线可用 | 数据量大时文件偏大（本期约 2MB） | ✅ **推荐** |
| B. 本地小服务 + 数据库 | Python/Node 服务 + SQLite | 支持复杂检索、历史趋势分析 | 需要常驻进程，普通同事不会启动 | 适合二期（做涨跌幅曲线时再上） |
| C. 在线系统 / 腾讯文档 | 上传到服务器或表格 | 随时随地访问 | 依赖网络与账号权限，数据保密性差 | 按单位要求另议 |

本刊是**双月刊**，一期 3000 余条价格，纯前端方案完全够用，且**零维护成本**。


## 三、日常更新流程（每月/每两期做一次）

1. **下载新期 PDF**，放进 `00_原始资料/信息价/` 目录（随便什么文件名）；
2. **双击运行更新**（或命令行执行）：
   ```
   python 信息价系统/tools/update_all.py
   ```
   新 PDF 自动抽取为 `data/<新期号>.js`，`data/index.js` 自动追加新期数；
3. **刷新浏览器页面**——"期数"下拉里自动出现新的一期，可随时切回历史期对比。

> 已抽取过的 PDF 会自动跳过（按文件名+大小识别），重复运行不会重复劳动。
> 若某期版式变化导致抽取异常，`_report.txt` 会列出"需复核"条目，按页码人工核对即可。

## 四、页面功能

- **期数切换**：多期并存，可回看任意历史期；
- **地区 / 类型双维度筛选**：8 个地区 × 材料指导价、干混砂浆、绿色建材、劳务、机械台班；
- **含税价 / 除税价 / 两者** 一键切换；多县区表自动展开为每县一列；
- **搜索**：材料名称、型号规格、备注模糊匹配，关键字高亮；
- **分组折叠**：按"黑色、有色金属…/灰砂石砖…"等原刊分类折叠浏览；
- **导出 CSV**：导出当前筛选结果（带 BOM，Excel 直接打开不乱码）；
- **打印**：自动隐藏控件，可直接打印存档；
- **可分享链接**：`index.html#r=海东地区&k=material&m=both` 直达指定地区/类型/口径。

## 五、数据准确性保障

本刊版式复杂，抽取器针对四类版式做了专门处理，并内置两道校验：

1. **跨页列块配对**：材料表一张逻辑表常拆到两页（首页有名称、续页只有价格列），
   按"行数严格相等 + 行索引对齐"合并，错位即报警；
2. **表头形态识别**：单层表头 / 县名+含税除税双层表头 / 标题行+表头 / 表头+地区名行
   四种形态自动区分；
3. **数字覆盖率校验**（`verify_extraction.py`）：把 PDF 原文中的所有数字与结果比对；
4. **地区别名归一**：如"格尔木"与"格尔木(唐古拉镇)"、"化隆"与"化隆(群科新区)"
   前后页写法不一致时自动合并，并在报告中提示。

本期实测：**28 个章节、3159 条价格，无空名称行、无漏价格行**，抽检（热轧带肋钢筋、
海东六县、海南绿色建材等）与 PDF 原文逐项一致。

> 原刊自身留空（如海南部分县无报价）会以"—"显示并在报告里注明，不是漏抽。

## 六、部署选项

| 方式 | 操作 |
|---|---|
| 本机使用 | 直接双击 `index.html` |
| 局域网共享 | 在本目录运行 `python -m http.server 8000`，同事浏览器访问 `http://你的IP:8000` |
| 放到单位服务器 | 把整个 `信息价系统/` 目录拷到任意静态目录即可 |

更新数据时只需替换/新增 `data/` 目录里的文件，页面无需改动。
